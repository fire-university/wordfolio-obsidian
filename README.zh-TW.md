# WordFolio

滑鼠滑過筆記裡的英文字，就跳出音標、發音與釋義——**完全不用連網**。想記住的字一鍵存成 Markdown 筆記，再用真正的間隔重複演算法複習。

釋義有**繁體中文**與**英文**兩種，跟著 Obsidian 的顯示語言走。所有東西都留在你自己的電腦上：沒有帳號、沒有伺服器、沒有任何追蹤。

> 電腦與手機都能用。詞庫只需要下載這一次（38.5 MB），之後查字永遠不必連網。

## 為什麼再做一個字典外掛

會 hover 的那幾個都串線上翻譯服務，所以上了飛機就不能用；而且中文那邊清一色走有道，只有**簡體**。能離線的則是純英英的詞表，連音標都沒有。至於會存生詞的，不是把字鎖在一個永遠進不了 vault 的資料庫裡，就是把「每隔幾分鐘跳一次提醒」叫做間隔重複。

## 安裝

1. 在 Obsidian 的社群外掛裡搜尋 **WordFolio**，安裝並啟用。
2. 第一次啟動時會問要不要下載離線詞庫（38.5 MB、58,250 個詞條）。按下去等它跑完，只需要這一次。
3. 在任何筆記裡把滑鼠停在英文字上。

之後想下載或修復，都可以到 **設定 → WordFolio → 離線詞庫**，或執行命令 **下載／更新離線詞庫**。

**下載中斷了就再執行一次。** 每個檔案都有 sha256 校驗，第二次會跳過已經下載好的、只重抓缺的或壞掉的——不會從 38.5 MB 重來。

檔案放在 `.obsidian/plugins/wordfolio/` 底下外掛自己的資料夾，不會進你的 vault。移除外掛時它們會一起消失，你的生詞筆記不會被動到。

### 在手機或平板上

觸控沒有 hover，所以手機版是按鈕觸發的：**點一下那個英文字**（游標落在字首、字中、字尾都算），再執行命令 **「查詢選取的單字」**。到 *設定 → 行動裝置 → 管理工具列選項* 把它加進工具列，或從長按選單裡叫出來。

先選取再查也可以；選取多個字會查片語。

手機上有兩件事不一樣：**從 Anki 匯入只能在電腦做**（AnkiConnect 是 Anki 桌面版的外掛），以及**浮窗不會自己跳出來**——這是刻意的，小螢幕上任何自動出現的東西都在擋你正在讀的那幾行。想要的話可以在設定裡把自動圖示打開。

## 浮窗會顯示什麼

底下每一種都是獨立的勾選項，順序也可以自己排。不看的就關掉。

**離線，隨時都在**

- 英式與美式 IPA 音標，附真人錄音發音（連不上時退回系統語音）。
- 繁體中文釋義（ECDICT）、英英釋義（WordNet），或兩個都要。
- 例句、同義詞與反義詞。
- 詞形還原——滑過 `unnerving` 查的是 `unnerve`，`ran` 查的是 `run`。
- 詞頻（BNC／COCA）、柯林斯星級、牛津三千核心詞、考試標籤。

**查的時候才抓，抓過就存起來**

- 劍橋、朗文當代、牛津學習者、Wiktionary。各自一個勾選項，某個字只有第一次查的時候會連網。

**選用的本地 AI**

- 指向 Ollama（或任何 OpenAI 相容端點），就可以問「這個字在我正在讀的這句話裡是什麼意思」、生成例句與搭配、或拆字根詞族。不用 API key、查的字不會離開你的電腦，而且預設關閉。

## 生詞本

按浮窗上的 **＋**，那個字就變成一篇 Markdown 筆記：音標與詞頻在 frontmatter，釋義在本文，你遇到它的那句話引在下面。**一個字一個檔**，就放在你的 vault 裡——搜尋得到、連結得了、Dataview 查得動、進得了 git。

同一個字再加一次不會重寫筆記，只會把新句子接上去，你自己寫的東西一個字都不會被動到。

筆記用哪種語言寫，跟介面語言一致；而 WordFolio **兩種都讀得懂**——之後切換語言不會讓已經寫好的筆記讀不出來。

## 複習

排程用 [FSRS](https://github.com/open-spaced-repetition/ts-fsrs)，跟新版 Anki 同一套演算法，狀態存在每篇筆記的 frontmatter 裡。

- **全頁生詞清單**：所有的字、狀態、下次到期、複習次數、忘記次數，可排序、可篩選、可搜尋。
- 清單最上面是**練習數據**：今天／最近七天複習量、連續天數、正確率、平均記憶強度，以及最記不牢的那幾個字。
- **每日新字上限**：一次匯入幾百個字之後，不會直接丟給你三百張永遠複習不完的卡。
- 複習視窗有四鍵評分、鍵盤快捷鍵，以及選用的拼字練習。

## 把別的地方的生詞接進來

如果你在瀏覽器用 **Language Reactor** 或 **Saladict** 存字，那些字會跑進 Anki 而不是你的筆記。WordFolio 可以把它們接過來（**從 Anki 匯入**，需要 AnkiConnect）：拿字跟它的上下文，音標與釋義用離線詞庫補齊。對 Anki 而言是**唯讀**的——不會改動也不會刪掉那邊的任何東西，複習排程仍然只有這個外掛在管。

反方向（**把生詞本送進 Anki**）也支援，但那是單向的；建議挑一邊當主力，不要兩套並行。

### 從 Kobo 電子書閱讀器

用 Kobo 內建字典查過的字也可以接進來（**從 Kobo 匯入**）。[PaperFolio](https://github.com/fire-university/paperfolio-obsidian) 同步時會把那些字寫進你的 vault，這裡讀的就是那個檔，所以路徑通常不用設定。打開**同步後自動匯入**，閱讀器上那顆同步按鈕就一路到底：讀書時按一下，字就已經在 Obsidian 等你了。

**在 Kobo 上：先查字，再畫線。** 只要文字被選取了就沒辦法再長按查字，所以順序是長按查字 → 看完關掉 → 再把那一句畫起來。這個順序有差，因為閱讀器只存那個字、不存它出自哪一句——那一句是 PaperFolio 從你畫的線裡找回來的。

## 隱私

查一個字會連網的情況只有兩種：你打開了那四個線上詞典的其中一個，或是按了某個還沒快取過的字的發音鍵。釋義、音標、例句、同義詞與所有排程都在本機。沒有帳號、沒有分析、沒有追蹤，而且外掛只會寫入你的生詞本資料夾與它自己的外掛資料夾。

## 開發

```bash
npm install
npm run fetch:sources   # 下載約 73 MB 的來源資料到 vendor/(gitignored)
npm run build:dict      # → dict/
npm test                # 17 份檢查,第一份需要 dict/ 已經存在
npm run build           # → main.js
npm run deploy          # 建置並複製進 vault
```

`npm run deploy` 預設寫到 iCloud 那個路徑的 vault；要換地方就設 `WORDFOLIO_VAULT`。

詞庫走另一個 GitHub release，標籤是 `dict-<版本>`；`src/settings.ts` 的 `DICT_VERSION` 綁住這一版要用哪個詞庫，兩邊對不上時 `npm test` 會擋下來。
